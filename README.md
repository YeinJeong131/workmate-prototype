# Workmate prototype

Prototype of our reimagined AI extension for the Technologies Reimagined pitch video.

- `index.html` is the page GitHub Pages shows. Open it in a browser to try it.
- `src/main.ts` holds the logic. Change names, roles and emails in `CONFIG` at the top.
- `src/template.html` holds the layout and styles.

After editing anything in `src/`, rebuild `index.html`:

```
npm install
npm run build
```

Filming tip: on the first screen, press the ` key to auto-type the example question.
